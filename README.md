# Elsewhere

Elsewhere is an Android roleplay app for character chats and episodic Worlds.

## Roadmap decision: memory retrieval

AI-assisted memory retrieval is intentionally deferred to a later milestone. It is not a missing release item. This release uses on-device retrieval and the existing memory controls. AI-assisted retrieval is a future option, not a requirement for using Worlds.
